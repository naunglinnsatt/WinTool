# 🛠️ WinTool - Windows System Utility Tool

WinTool သည် Windows System Control Panel များ၊ Administrative Tools များနှင့် System Maintenance Command များကို နေရာတစ်ခုတည်းမှ လွယ်ကူလျင်မြန်စွာ ခေါ်ယူ အသုံးပြုနိုင်ရန် Python (CustomTkinter) ဖြင့် ဖန်တီးထားသော Modern Desktop Application ဖြစ်ပါသည်။

---

## 🚀 Download & Installation

### Portable (.exe) ကို တိုက်ရိုက် သုံးရန်

 `wintool.exe` ကို Download ရယူ၍ တိုက်ရိုက် Run နိုင်ပါသည်။

---

## ⚠️ Troubleshooting (Windows Security သတိပေးချက် တက်လာပါက)

စက်အချို့တွင် Unsigned `.exe` ဖိုင်များ ဖြစ်သောကြောင့် Windows SmartScreen မှ ပိတ်ဆို့ထားပါက အောက်ပါအတိုင်း ပြုလုပ်နိုင်ပါသည်။

1. Windows ရဲ့ **Start Menu** (သို့မဟုတ် Search) ထဲမှာ **Windows Security** လို့ ရိုက်ရှာပြီး ဖွင့်ပါ။
2. **App & browser control** ဆိုတဲ့ Menu ကို နှိပ်ပါ။
3. **Smart App Control settings** ကို နှိပ်ပါ။
4. **Smart App Control** နေရာမှာ **Off** သို့မဟုတ် **Evaluation** ကို ပြောင်းပေးလိုက်ပါ။
5. ပြီးရင် `wintool.exe` ကို Double-click ပြန်ခေါက်ပြီး အဆင်ပြေပြေ ပွင့်သွားပါလိမ့်မယ်။
